# Inkling roadmap

Ideas offered for Inkling that are not built yet. Tick them off (`[x]`) as they ship, and add new ones under the right heading.

## Publishing: format the book for sale (Vellum and Atticus competitor)

The full plan, KDP requirements and best practices are in [PUBLISHING-PLAN.md](PUBLISHING-PLAN.md).

- [x] Book details: subtitle, series, imprint, ISBNs, edition, description, keywords
- [x] Front matter: half title, title page, copyright page generator, dedication, epigraph, table of contents
- [x] Back matter: acknowledgments, about the author, also by, newsletter/store links
- [ ] Back matter extras: about-the-author photo, reading-group guide, cast list from story pages
- [x] Chapter types: numbered, unnumbered (prologue, epilogue), part dividers, with chapter numbering in words or digits
- [x] Book styles: chapter heading layouts, ornaments, drop caps, small caps, scene-break ornaments
- [ ] Copy and tweak a book style (own fonts, sizes and heading images)
- [x] Store-ready ebook (EPUB for Kindle, Apple Books, Kobo, Google Play, Nook): cover, landmarks, NCX, checked by EPUBCheck
- [ ] Ebook extras: embedded fonts, store-specific links (a different link list per store)
- [x] Print-ready paperback and hardcover PDFs: KDP trim sizes, gutter by page count, chapters on right-hand pages, running heads, page numbers, even page count
- [x] Spine width readout (and full cover size)
- [ ] Cover wrap builder (front, spine and back in one PDF)
- [ ] Hyphenation for print (Chromium only hyphenates on macOS), and lining up the last lines of a spread
- [ ] Print extras: roman numerals in the front matter, chapter heading images, bleed, large-print preset
- [ ] Live preview: ebook devices and print spreads
- [x] Pre-flight check before export (cover size, empty chapters, TK/TODO, straight quotes), with a one-click typography tidy
- [ ] Special paragraphs: block quote, letter, verse, text message
- [ ] Box sets (several projects in one ebook)
- [ ] IngramSpark preset; DOCX for print
- [ ] Submission kit: query letter, synopsis and author bio templates

## Story development

- [x] Series bible: characters, places and timelines shared across books in a series
- [x] World-building: magic/technology rules with costs and limits, languages and glossaries with pronunciation, invented calendars, currencies
- [x] Map maker: upload or draw a world map, pin story pages to it, see which scenes happen where
- [x] Character arcs: goal, wound, lie and change per character across chapters, as a line chart
- [x] Pacing graph: tension, action vs reflection and scene length across the book
- [x] POV and screen-time balance: words per character and viewpoint, chapter by chapter
- [x] Subplot tracker: warns when a thread disappears for too long or never resolves
- [x] Foreshadowing log: setups linked to payoffs, unresolved setups listed

## Writing and revising

- [ ] Revision mode: filter words, weak adverbs, repeated words, long sentences, passive voice, your own pet words
- [ ] Comments in the margin, with replies and resolving
- [ ] Suggested edits and revision marks (track changes)
- [ ] Split a scene at the cursor; merge a scene with the next
- [ ] Double-click to rename a scene in the binder
- [ ] Paste from Word or Google Docs keeping italics and bold
- [ ] "First draft" mode that won't let you delete
- [ ] Typewriter sounds (key clacks and the carriage-return ding)
- [ ] Beta reader links: read-only copy readers can highlight and comment on, with questions and a "where readers stopped" heat map
- [ ] Editor handoff: export to Word with comments, import tracked changes back
- [ ] Readability and style report: sentence variety, dialogue tags, clichés, crutch phrases, compared with genre averages
- [ ] Personal sensitivity and consistency checklist per book
- [ ] Compare whole drafts (Draft 1 vs Draft 2) side by side
- [ ] Proofread by listening to the whole book read aloud

## Daily writing life

- [ ] Research clippings: save web pages, images and PDFs into the project and link them to scenes
- [ ] Dictation: speak a scene with the computer's speech recognition
- [ ] Writing retreat mode: full-screen timer and goal, no menus, summary at the end
- [ ] Accountability buddies: share streaks and goals with writing friends without sharing the book
