# Inkling: notes for Claude Code

Single-file app: `index.html` holds markup, CSS and one IIFE of vanilla JS. No dependencies or build step. Only external requests are Google Fonts (Instrument Sans, Literata, IBM Plex Mono).

The same file runs in three places: the Claude artifact, a plain browser, and the Electron desktop app in `desktop/` (see `desktop/README.md`). Keep `index.html` working in all three; never fork it for the desktop.

## Data model

State `S = { meta, sc, en, tl, ch, nt, ol, rm, ft, ss, sn, tr }`. Every map except `meta` is listed in `DOCS`; each record saves as its own doc, so a new kind of record only needs adding there (plus a normalizer pushed onto `ADD_DOCS`, as `sn` does). Every saved record gets `_m` (last change, ms), `_dev` (the `DEVICE` id) and `_by` (writer name, `ME.name`) stamps in `dirty()`; deleting a record goes through `forget(key)`, which leaves a tombstone in `meta.gone{key:time}` (kept 180 days). Shared projects merge with these (see Sharing below):
- `meta`: `v` (save format, `FORMAT`), title, author, goal, target, `chapters[{id,title,open,scenes[]}]`, `scenes{id:{title,status,words}}`, `ents{id:{id,type,name,aliases,tag}}`, `tls[{id,name}]`, `ols[{id,name}]`, `nts[{id,name,kind}]`, `rms[{id,name}]`, `fts[{id,name}]` (order of timelines, outlines, notes, relationship maps, family trees; a note's `kind` is `page` or `board`), `secs{ol,nt,tl,rm,ft,place,thing:bool}` (which optional binder sections are shown, see `OPT_SECS`/`secOn()`; `rm` and `ft` start off), `labels{ol|nt|tl|rm|ft|char|place|thing:{p,s}}` (user names for binder sections, plural and singular; read them through `LP(t)`/`LS(t)`, never `TYPES[t].label`, and escape them), `pet{name,total,color,wear{head,face,neck,hand},got{achId:time},flags{early,night}}` (`normPet()`; personal, see Inky below), `pomo{focus,short,long,every,goal,autoBreak,autoFocus,sound}` (focus timer settings, minutes; `normPomo()`), `todo{d,items[{id,text,done,old,auto,sc,c}]}` (today's to-do list, `normTodo()`; personal; `todoRoll()` clears finished tasks on a new day and marks carried-over ones `old`; `auto` `goal`/`sprint`/`fin` tick themselves through `todoTick()` from `credit()`, `pmEnd()`, `sceneFinal()`; `c` = counted in `pet.tasks`), `days{YYYY-MM-DD:newWords}`, `mark` (today's cheer flags), `exp{fmt,byline,contact,font,page,title,chNew,brk,uid}` (export choices, `normExp()`), `fields` (custom story page fields, see below), `gone`, `layout{hide{key:true},order[]}` (what shows on screen and the Inkling panel's section order; `normLayout()`, `LO_INSP`, `LO_GROUPS`, `LO_PRESETS`; personal; new projects start from `LOOK.layoutDef`; `applyLayout()` puts `lo-<key>` classes on `#app`, view `{k:'layout'}` = Window › Project settings, `renderLayout`), `plan{on,mode,target,start,by,base,based,wd[7],off{day:1},auto,log{day:{p,g}},doneAt}` (deadline planner, `normPlan()`; personal; mode `total` counts the manuscript from `base`, `new` sums `meta.days` from `start`; `planState()` gives today's goal = words left at the start of today over the writing days left (`planDays`), status ok/ahead/behind/soon/past/done against an even line over writing days, pace and projected finish; `planSync()` from `updateStats()` sets the base, logs the day, sets `meta.goal` when `auto` and cheers at the target; `planPaint()` draws `#planLine` in Today; view `{k:'plan'}`, `renderPlan` with `planChart` and `planCal`; `planGreet()` in `greet()`), `writers{nameKey:{name,days,pet,mark,goal,pomo,todo,layout,plan,devs,at}}` (each writer's personal stats on a shared project; the top-level `days`, `pet`, `mark`, `goal`, `pomo`, `todo`, `layout`, `plan` are this device's working copy, see `PERSONAL`, `stampMine()`, `adoptMine()`), `saved` timestamp.
- `sc[id]`: `{text, synopsis, notes, stickies}` per scene. `stickies` are margin sticky notes `[{id,text,color,side:'l'|'r',y}]` (`normStickies`; `y` in px from the top of the page; drawn by `stkDraw()` in `#stkLayer` beside the `.sheet`, folded into edge tabs when the margin is narrower than `STK_W`; `stkBind()` handles add (button or double-click in the margin), edit, colour, delete and dragging). `text` is plain text with formatting markers: `**bold**`, `*italic*`, `__underline__` (older `_italic_` still reads). `fmtParse()` gives the visible text, a style bitmask per character and a map back to stored offsets; use `plainText()` wherever text is shown, searched or checked, and `rawAt()`/`rawEnd()` to turn visible offsets into stored ones.
- `en[id]`: `{fields:{}, pic}` per story page. `pic` is `{a, l, cap, shape, size, fit, px, py, zoom}` (`px`/`py`: focal point in %, `zoom` 1–4; framing is applied by `picStyle()` for `<img>` and `picSvg()` for map and tree bubbles; edited by dragging in Layout › Adjust framing): `a` is an artifact asset id (shown from `/_blob/<id>`), `l` means a resized data URL in `localStorage` key `inkling:img:<entId>` (outside the project record; JSON backups carry those as `imgs`). Use `picSrc()`, `setPic()`, `removePic()`; deleting a page calls `dropPic()`. Entity types: `char`, `place`, `thing`.
- `tl[id]`: one timeline: `axis{start,step,px,fmt,names,cycle,snap}`, `cardW`, `density`, `showWhen`, `showMarks`, `grid`, `lanes[{id,name,color,hide}]`, `cards{id:{lane,at,len,title,body,when,icon,color,style,scene}}`, `marks[{id,label,at,len,color}]`, `ticks{columnIndex:label}` (renamed header columns), `corner`, `tickSize`. Positions are in axis units, not pixels. `normTl()` validates everything.
- `ch[id]`: `{notes}` per chapter, shown above that chapter's corkboard.
- `nt[id]`: `{text, ideas[{id,text,color}]}`; a `page` uses `text`, a brainstorm `board` uses `ideas`.
- `ol[id]`: `{num, showNotes, items[{id,text,note,depth,done,open,noteOpen,scene}]}`. The outline is a flat list with `depth` (max `OL_MAX`); an item's children are the following items with a greater depth (`olEnd`). Indent, outdent and moves always carry the whole block. Templates live in `OL_TPL`, with each line's rough place in a story (%) in `OL_POS`. A template line keeps its original wording in `tpl{t,n,p}`; choosing a template (`olApplyTemplate`) replaces untouched template lines and keeps anything the writer typed (changed notes move to the matching beat by name or by `p`; renamed template lines and the writer's own lines follow that beat). Older outlines without `tpl` are recognised by known beat names. `ui.olUndo` holds one step of undo.
- `ss[id]`: one writing session from the focus timer: `{start,end,planned,mins,words,net,done,scenes[],cyc}` (`cyc`: the run of sessions up to a long break, `T.cyc`; `pmReport(cyc)` shows the writing report with words per minute after the last one, from `pmEnd`/`pmSkip` and from Writing sessions) (`words` = new words credited while it ran, by the same rules as the daily goal; `net` = change in total words; `done` = ran to the end rather than stopped early). Shown and deleted in the Writing sessions view (`renderSs`, view `{k:'ss'}`).
- `sn[id]`: scene snapshot `{scene, at, name, text, words, auto}`; `auto` is `''` (saved by hand), `daily` (before the first change of the day, `snDaily`), `restore`, `replace` or `merge` (the losing text when two writers changed a scene). Automatic ones are capped at `SN_AUTO_MAX` per scene. `snTake`, `snList`, `snDrop` (when a scene is deleted). View `{k:'snap',id}` (`renderSnap`) compares with `diffHtml` (paragraphs, then words).
- `tr[id]`: Trash item `{kind, at, by, title, sub, d}` (`kind`: scene, chapter, ent, tl, ol, nt, rm, ft; `d` holds what `trashRestore()` needs: records without stamps (`bare`), position, a scene's snapshots (`snOf`), a page's map and tree links). Every `del*` function calls `trashPut()` first (which toasts an Undo); a page's picture is kept until `trashDrop()`. `trashPurge()` (from `renderAll`) drops items older than `TRASH_DAYS`. View `{k:'trash'}`, `renderTrash`.
- `rm[id]`: relationship map: `kinds[{id,name,color,dash,hide}]`, `nodes[{id,ent,name,x,y,color,size,note}]` (a node links a story page via `ent` or is a free bubble with `name`), `edges[{id,a,b,kind,dir,label,note}]` (`dir` is `none`, `ab`, `ba` or `both`), `view{x,y,k}`, `labels`, `pics`, `size`, `def` (last-used kind).
- `ft[id]`: family tree: `kinds[{id,name,color,dash,sym}]` (partnership types), `people[{id,ent,name,title,born,died,color,of,ptype,note}]`, `unions[{id,a,b,kind,label,note}]`, `view`, `cardW`, `gap`, `dates`, `titles`, `pics`. A person's parents are the union in `of`; a union with only `a` is a single parent. There are no stored positions: `ftLayout()` assigns generations (partners and siblings share a row, parents sit one row above their children) and orders each row by parent position. Order within a family is the order of `people`; Move left/right swaps entries. `ftTidy()` drops unions left with no parents, or with one parent and no children.

## Persistence

Save format: `FORMAT` (now 2) is stored in `meta.v`. `migrate()` runs `MIGRATE[n]` for each older version on load; when the format changes, bump `FORMAT` and add a step. A project from a newer format throws `code:'newer'` and the app goes read-only (`lockNewer`, `ui.locked`), so an old copy never overwrites newer work. `flush()` hands dirty keys and deletions to the active adapter in `STORES` (`local`, `claude`, `desktop`); a future cloud store is one more entry there.


`flush()` writes dirty docs. In the original Claude artifact it used the artifact `db` capability, one doc per `meta` and `<prefix>_<id>` for each `DOCS` prefix (`sc`, `en`, `tl`, `ch`, `nt`, `ol`, `rm`, `ft`), under `data/users/<id>`. Outside that environment `window.claude` is absent, so it falls back to `localStorage` key `inkling:project` (mirrored on every save either way). Keep scene text in its own doc/key so no single record gets large. The artifact declares `db`, `user`, `downloads` and `assets` (pictures); never put image bytes in a doc.

Desktop (`window.inklingDesktop`, kept in `DESK`): `desktop/main.js` stores each project as a folder (`project.json`, `info.json`, `pictures/`, `backups/`, `.inkling-here/`) in the projects folder (Documents/Inkling Projects unless changed in Settings: `chooseDir`/`useDir`), or anywhere else as a linked (shared) project (`settings.links`, `projDir()`). `flush()` sends the whole `snapshot()` to `DESK.save` (atomic write plus a timed backup); `PJ.id` is the open project and `PJ.base` the version last read or written. `DESK.load(id)` returns `{data, others}`. Updates: electron-updater (packaged builds only) sends `ink:update` states to `showUpdate()` (Restart to update on Windows/Linux; Download on unsigned macOS); see RELEASING.md. `APP_VERSION` is set from `desktop/package.json` by `prepare.js` (and by `desktop/scripts/version.js` in the source). Pictures are files (`pic.f`) shown through the `inkpic://p/<project>/<file>` protocol. Projects UI: `openProjects()`, `deskOpen()`, `deskNew()`, `deskImport()`. The window waits for `deskFlush()` before closing. The page talks to the computer only through the fixed list in `desktop/preload.js`; main validates every id and file name. `desktop/scripts/prepare.js` builds `desktop/app/` from `index.html` (bundled fonts, strict CSP, no network), so a desktop change that needs network access will fail there.

Backups (`doBackup`) carry every picture as a data URL in `imgs`, whatever its storage (`collectImages`); restoring places them where that environment keeps pictures (`adoptImages`).

## Sharing (desktop)

Co-writers share a project folder through Dropbox/Drive/OneDrive/iCloud (user guide: SHARING.md; in-app: view `{k:'help'}`, `helpShareHtml()`). Saves are compare-and-swap: main keeps the hash of `project.json` as last read/written (`known`) and `DESK.save` answers `{conflict:true}` if the disk differs. `deskSync()` then `DESK.read()`s the disk version plus any sync-service conflicted copies (`STRAY_RE`), `mergeIn()` merges (`mergeProjects(base, ours, theirs)`: records three-way by `canon()` equality, newer `_m` wins a true clash, a scene clash keeps the loser as an `auto:'merge'` snapshot; deletions use `meta.gone` times; meta merges field by field and list order with `mergeOrder`; `fixMerged()` repairs the indexes), `patchState()` updates the live state in place so open screens keep working (re-rendering only the view whose data changed, `viewSig`), and saves with the read's token (`DESK.clearStrays` then files the copies in backups). If nothing of ours differs it just `DESK.adopt`s the disk version (no write, so two computers don't ping-pong). `syncCheck()` runs every 8 s and on focus. Presence: `DESK.here()` writes `.inkling-here/<device>.json` (name, scene, version) and returns the others (`ui.others`, `paintHere()`: top-bar chip, binder letters, note above a shared scene, version warning). Writer identity is `ME.name` (localStorage `inkling:me`, Settings › You, `setMyName`); writing sessions are filtered to the writer (`mySs()`). Share UI: `openShare()` (move into a sync folder: `DESK.shareMove`), `openSharedPick()` (`DESK.openShared`), Projects › Remove from list (`DESK.unlink`; linked projects can't be trashed).

## Key behaviours

- Name links: `buildLinker()` makes one case-sensitive regex from every entity name and alias. `relinkEditor()` re-renders spans only when the link set changes, and restores the caret by visible-text offset. The editor is `contenteditable="true"`: `renderText()` draws `<b>/<i>/<u>` and name links from stored text, `getText()` serializes the DOM back with `fmtSerialize()`; Enter inserts a line break (`insertLineBreak`) keeping the line's leading tabs (`LOOK.keepIndent`), Tab/Shift+Tab indent (`edIndent`: a tab at the caret, or every selected line), paste is plain text line by line, Ctrl+B/I/U and the B I U buttons call `fmtCmd()`, and `beforeinput` makes curly quotes, em dashes and ellipses (`LOOK.smart`). Undo/redo is Inkling's own per scene (`UNDO`, `undoNote` from `onType`, grouped at 1 s pauses, `ui.bigEdit` for one-step changes; `edHist`; the browser's `historyUndo` beforeinput and the desktop Edit menu land there too). `edSel` gives selection offsets in visible text with line breaks (`visAt`); `edApply` re-renders and saves. Also `paintSceneWc` (selected words), `followCaret()` from `onType` (scrolls `#main` so the caret stays clear of the bottom edge and a phone keyboard, measuring an empty new line with `caretRect()`; centres it with `LOOK.typewriter`), read aloud (`readAloud`, `raStop`, speechSynthesis one paragraph at a time with a `::highlight(inkread)`), `showKeys()`. Window actions (`winAct(a, src)`: layout, tBinder, tInsp, focus, keys, undo, redo and more) come from the ⋯ menu (`ui`), the desktop menus (`menu`) and the keyboard (`key`); one action arriving from both `key` and `menu` within 200 ms (a desktop accelerator) runs once, repeats from one source always run.
- Continuity (`contCheck()`, cached a few seconds; view `{k:'cont'}`, `renderCont`): facts from each story page's `fields.facts` (`parseFacts`: `eyes`, `hair`, `age` lines) are checked sentence by sentence against the nearest linked name; capitalised words one edit from a name are possible typos (`lev1`); characters who stop appearing or vanish for 5+ chapters; pages never mentioned. Hidden items go in `meta.contIgnore{key:1}` (`contKey`). The story page shows Key facts, first/last seen and its own issues (`entContHtml`); the binder shows mention counts (`mentionCounts`); the inspector links to the check.
- Drag to reorder: `dragSort(root,{item,handle,zones,grid,drop})` (pointer-based; touch needs a short hold). Used for binder scenes (`moveSceneTo`), chapters, planning lists (`moveInList` on `meta.tls/ols/nts/rms/fts`), corkboard cards, outline lines with their children (`olDrop`, grip `.ol-grip`) and brainstorm ideas.
- Pet credit: `credit(delta)` counts only positive deltas, ignores single changes over 600 words (pastes), and drives cheers, confetti and level-ups. Stages are in `STAGES`; the words needed are a share of the novel length goal (`STAGE_FR`, `stageAt(i)`), and `pet.rank` keeps the highest rank reached (`petStage()`), so raising the goal never demotes Inky.
- Inky: `petSVG(mood, stage, look)` draws the pet with `look.color` (`PET_COLORS`, applied as `--pet*` variables by `petStyle`) and `look.wear` per slot (`'auto'` follows the stage: quill, glasses, beret, laurel; other items are SVG in `PET_ART`). `ACH` lists achievements `[id, name, how, reward item, stat, target]` over `petStats()`; `checkAch()` marks new ones in `pet.got` and cheers (`checkAch(true)` at open catches up quietly). Rewards are in `PET_ITEMS` (slot `room` items are drawn by `roomSVG()`, behind the pet in the inspector and in the room view `{k:'den'}`, `renderDen`). Notices: `addEntity`, `addChapter`, `sceneFinal()`, scene word milestones in `onType`, time-of-day flags in `credit`, `greet()` on open. `cheer()` respects `LOOK.petTalk` (`chatty`/`quiet`/`off`) and `LOOK.confetti`. Sprint together: presence carries `sprint` (end time) and `pet`; `paintPals()` shows sprinting co-writers' pets, `pmJoin()` joins their sprint.
- Inky reads over your shoulder (`LOOK.peek`, on unless switched off in the room): `readPage(vis, caret)` reads the scene's visible text up to the end of the caret's line, sentence by sentence with recency weights: mood (`PK_MOOD`, last ~12 sentences, negation `PK_NEG` and intensifiers `PK_AMP`), weather/time/setting (`PK_WEATHER`, `PK_TIME`, `PK_PLACE`, long memory), events in the last two sentences (`PK_EV`: key, regex, face, prop, strength), characters and places from name links, dialogue share, pace, a repeated word (`echo`), and a nearby continuity fact clash (`peekFacts`). `peekRun(mode)` runs on a pause in typing (`'type'`), on opening a scene (`'open'`: `peekWhere` says where we are) and when the caret moves (`'move'`, silent); `peekLine` picks at most one remark (`PK_LINES`, `{who}`/`{place}` filled by `pkFill`), rate-limited per kind, never over a recent cheer, retrying a waiting one. `peekFace` maps the reading to a face (new moods in `PET_ARMS`/`petSVG`: scared, tense, sad, love, angry, curious, glee, laugh, cozy) and `look.react` props (`REACT_ART`); `paintPet()` redraws the inspector pet, the room (`roomSVG` draws the story's sky, `winView` scenery, `winWeather`, mood tint; `data-read` on the svg) and the peeking pet (`#peek`, shown in focus mode and the tabbed layout).
- Search everything (`searchAll(q,{mc,ww})`, view `{k:'search'}`, `renderSearch`, Ctrl+K and the binder's search box): hits `{area,label,where,n,snip,open}` over scenes (text first), chapters, story pages, notes and ideas, outlines, timelines, maps and trees; `saOpen()` selects scene matches through `ui.findSel`, opens a timeline card (`tlOpenCard`), a map or tree selection (`ui.cvFor`/`ui.cvSel`), or flashes the line, idea or field.
- Side by side (`ui.split`, pane `#split`, `renderSplit`, `splitOpen/Close/Swap`, `SPLIT_KINDS`; Ctrl+\\, Alt+click or the split buttons in the binder, `#spBtn` above a scene): scenes, outlines and timelines read-only, story page fields and notes pages editable; `splitTouch()` from `dirty()` redraws it when its item changes elsewhere. Grid columns come from `applyCols()` (`--cols` on `#app`: binder, page, split, inspector, minus hidden ones and focus mode).
- Getting around: `startView()` reopens the last view and `posRestore()` (from `renderMain`) puts a scene's caret and scroll back, from localStorage `inkling:pos:<project>` (`posKey`, `posPut`, `posSaveScene` on scroll, on caret moves via `ui.edRange`, on leaving a scene and on pagehide). Quick switcher `openQs()` (Ctrl+P; `qsItems`, `qsScore` subsequence scoring, recent views first, Alt+Enter = side by side). `sceneStep(±1)` (Alt/Ctrl+PageDown/Up, `.sc-nav` under a scene), `goBack()`/`goFwd()` with `ui.fwd` (Alt+←/→, ⌘[ ], mouse buttons 3/4, the forward button in `backBtn`). Desktop Go menu sends `qs`, `back`, `fwd`, `next`, `prev` to `winAct`.
- Binder right-click: `binderMenu` → `ctxMenu(x,y,items,title)` (items `[label, fn, {danger,on,sub}]` or `'-'`); `dupScene`, `dupChapter`, `dupEnt` (without its picture), `dupDoc`; scenes rename inline like chapters (`ui.rename`). Word targets: `meta.scenes[id].goal`, `chapters[].goal` (`setTarget` via `askValue`, `tgBar` in the binder, cheers in `onType`, the scene's target in the inspector). Story page fields: `entFields(type)` reads `meta.fields{type:[[key,label]]}` (`normFields`, `fieldsEditHtml`, `bindFieldsEdit`, `ui.fEdit`) before `TYPES[type].fields`; always use it. `bindPicDrop` sets a page's picture from a dropped or pasted image.
- Timeline (`renderTl`): `drawTl()` redraws only the board, `drawSide()` only the card/settings panel, so inputs keep focus while the board updates. Tick labels come from the `fmt` template (`{n}`, `{name}`, `{cycle}`, `{i}`), unless the column (`tlIdx`) has a custom label in `ticks`; cards in that column show it too. Cards stack into rows within a lane when they overlap. Mouse drags the whole card; touch drags only the grip or the resize edge so the board still scrolls. Lane names are edited inline (`tlEditLane`) or in Customize; lanes also have an optional `note` (what the lane tracks). Card colour `''` means "use the lane colour"; colours are token names or `#rrggbb`.
- Maps and trees (`renderCv`) share one pan-and-zoom SVG (`cvApply`, `cvZoom`, `cvFit`, `cvWorld`); `cvSelect()` opens the side panel and pans to keep the selection visible. On a map, a selected bubble shows a `+` handle; dragging it onto another bubble calls `rmConnect()`. Deleting a story page calls `unlinkEnt()`, which turns its bubbles and tree people into unlinked ones with the same name. Story pages list their map relationships and tree family (`relHtml`).
- Focus timer: runtime state is `T` (never saved); `pmStart/pmPause/pmStop/pmSkip/pmEnd` drive it from `endAt` timestamps, so it stays right in a background tab. `credit()` adds to the running session; `pmRecord()` saves it (sessions under a minute with no words are dropped). `pmHalt()` saves a running session before the project changes or the desktop window closes. The chime is generated with Web Audio, no files.
- Layout: three panes above 1080px, tabbed below. The side panes' widths are `--bw`/`--iw`, dragged on `#szL`/`#szR` (`bindSizers`, `setSide`, `applySides`, kept per device in `LOOK.bw`/`LOOK.iw`; `sideRoom()` always leaves the page about 440px). All colours are CSS tokens with light and dark palettes; Settings can force one with `data-theme` on `<html>`.
- Settings (`renderPrefs`, view `{k:'prefs'}`): appearance is per device in localStorage `inkling:look` (`LOOK`, `applyLook()` sets `--ed-font`, `--ed-lh`, `--ed-w`); the desktop sections (folder, updates, spelling language) come from `DESK.prefs()`.
- Saving: automatic; `saveNow()` (File › Save, Ctrl/Cmd+S, menu Save) flushes at once and confirms.
- Dialogs: `ask(title, html, [[value,label,style]])` returns a Promise of the chosen value; use it instead of `confirm()`. Toasts can carry one action button: `toast(msg,{act:[label,fn]})` (the Trash's Undo).
- Export (`openExport`, `doExport`): `.docx` and `.epub` are built in the page with a small stored-zip writer (`zip`, `crc32`); PDF goes to `DESK.pdf` (printToPDF with the running header) or the browser's print window. Paragraphs are lines; `*x*`/`_x_` are italics (`runs`).
- Find and replace (`renderFind`, view `{k:'find'}`): `findAll` over scene text; replacing uses `setSceneText` (no pet credit) after a `replace` snapshot. A clicked result sets `ui.findSel` so `renderScene` selects it.
- Word history (`drawWcBox`, top of Writing sessions) is one series of bars from `meta.days`, with the goal as a dashed line, hover tooltip and a table view.
- Tour: `TOUR` steps, `startTour(force)`, shown once per device (localStorage `inkling:tour`).

## Tests

`npm test` (Playwright) runs `tests/web.spec.js` in Chromium against `index.html` and `tests/desktop.spec.js` against Electron (needs `npm ci` in `desktop/`, and `xvfb-run -a` on a headless Linux). `.github/workflows/test.yml` runs them on every push; the desktop release workflow runs them before building. Add a test with each feature.
